# Phone Shield — Business Website

Poster-based business website for **Phone Shield** (mobile security + EMI security for retailers).

- Single-page, fully responsive (mobile + desktop)
- All content in Hindi
- Embedded SVG logo, inline CSS — no external assets
- Sections: Features, How it works, Pricing, Auto-pay/EMI, Contact

## Deploy to GitHub Pages
1. Create a new repo on github.com (e.g. `phone-shield`)
2. Push this folder to the `main` branch:
   ```bash
   git add -A
   git commit -m "Phone Shield website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/phone-shield.git
   git push -u origin main
   ```
3. Repo → **Settings → Pages** → Source: `Deploy from a branch` → branch `main` / root → Save.
4. Your site will be live at `https://<your-username>.github.io/phone-shield/`
